# Shell Scripting dan Automation

# Deskripsi
Repository ini berisi hasil praktikum Sistem Operasi Modul 3 tentang Shell Scripting dan Automation, meliputi variabel, kondisi, perulangan, cron job, systemd timer, serta debugging dan logging.

# Tujuan
- Memahami dasar shell scripting
- Menggunakan variabel, kondisi, dan perulangan
- Melakukan automasi dengan cron job dan systemd timer
- Melakukan debugging menggunakan journalctl dan dmesg

# Tools
- Linux (Ubuntu)
- Bash Shell
- Cron
- Systemd


Cara Menjalankan Script

chmod +x script/log_time.sh
./script/log_time.sh
